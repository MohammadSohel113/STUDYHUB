STUDYHUB - Programming Learning Platform
========================================

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   python -m pip install -r requirements.txt
4. Then run:
   python app.py
5. Open the local address shown in the terminal, normally:
   http://127.0.0.1:5000

Features included in this starter:
- Student Sign Up
- Student Sign In / Logout
- Student Dashboard
- Programming language courses
- Lesson progress
- Final exams
- Exam score and pass status
- Responsive professional UI
- SQLite database

The project is intentionally structured so more lessons, questions,
languages, coding practice and certificates can be added next.
